How to read this view

One row per peer (by host). Each marker is one JSONL event. X axis is wall-clock seconds since the earliest event in the loaded files. Color encodes the event layer (legend at top).

Click any marker to inspect its full JSON in the side panel. If the event carries a trace_id, every other event sharing that trace is highlighted and arrows are drawn between consecutive events in time order — that's the message's hop chain across processes/peers.

What's plotted: per-event probe writes (layer/event tuples like msg/new, msg/outbound_routed, msg/dispatched, peer.set/added, net.mystery/aged_out). Counter snapshots (the aggregated periodic dumps) are shown as small grey markers when visible — most of the diagnostic value lives in the per-event layers.

Companion tools: scripts/probe-tail.py --dir <d> aggregates counters across peers; scripts/probe-flow.py <trace_prefix> reconstructs a trace text-mode.
